QHSE Pro Android — بناء APK من الهاتف باستخدام GitHub Actions

المشروع يحتوي على تطبيق Android بسيط يفتح واجهة HTML المرفقة دون اتصال للواجهة الأساسية.

إنشاء APK عبر GitHub:
1. أنشئ مستودعًا جديدًا على GitHub باسم QHSE-Pro-Android واجعله Private إن كان يحتوي على أي بيانات خاصة.
2. ارفع محتويات هذا المجلد إلى جذر المستودع مع الحفاظ على بنية المجلدات، وليس ملف ZIP وحده. يجب أن يظهر في الجذر settings.gradle و build.gradle ومجلد app ومجلد .github.
3. بعد رفع الملفات، افتح تبويب Actions في المستودع. إذا طلب GitHub تفعيل Actions، وافق.
4. اختر سير العمل "Build QHSE Pro APK" ثم Run workflow، أو انتظر تشغيله تلقائيًا بعد الدفع إلى main.
5. افتح عملية التشغيل المكتملة، ثم نزّل Artifact باسم QHSE-Pro-APK.
6. فك ضغط الـ Artifact على الهاتف؛ ستجد app-debug.apk. افتحه واسمح بالتثبيت من هذا المصدر عند طلب Android.

إذا لم يظهر Actions:
- تأكد أن ملف .github/workflows/android.yml موجود في المسار الصحيح.
- يجب أن يكون الفرع اسمه main، أو عدّل اسم الفرع في الملف.
- لا ترفع ZIP فقط؛ GitHub Actions يحتاج الملفات مفكوكة في المستودع.

ملاحظة تقنية:
- هذه نسخة تجريبية WebView مع HTML محلي وبيانات محلية، وليست نسخة إنتاجية.
- لا توجد قاعدة بيانات مشتركة أو مزامنة Supabase.
